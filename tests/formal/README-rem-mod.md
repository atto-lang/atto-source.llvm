Run `python tests/formal/verify_remainder.py --solver /path/to/trusted/z3` with llvmlite 0.47.0 and Z3 4.13.3. The local replay used actual libz3 4.13.3.0 through a CLI-compatible adapter. Exact representative fixture and extractor/runner blobs verified: 1da16e7fde729f94584c82eea5315f249b0f1ca3, aff749ca6c99ddc623c9de6007e599671456032e, 15b6114e3f1ef16c4d7648911eadd149f1d22b01. Two correct IR variants, five solver-detected mutants, seven structural negatives: 14/14. Four remainder and six modulo UNSAT obligations; three reachability SAT controls per function. Solver must execute successfully with the prescribed transcript. The model trusts LLVM's defined signed remainder semantics and its range. It proves terminal zero guard equivalence, safety on the admitted path, unchanged divisor outside -1, substitute +1 for -1, and (for modulo) exact widened Euclidean correction and bounds for any valid remainder. It does not prove the LLVM intrinsic implementation, the complete program, optimization, machine code, guest Result/Error, or actor behavior.
