# Checked unsigned scalar LLVM/Wasm candidate

This explicitly selected closed unsigned source compiler emits LLVM IR, not precomputed fixture answers. Compile `tools/atto_checked_u64.cpp` with C++20, then pass a bounded Atto source to stdin. The result is IR with a full-width `atto_guest_main` i64 ABI interpreted as unsigned. The parser admits homogeneous u64/uint root functions, canonical unsigned decimal literals, parameters, calls, grouping, +,-,* only. The compiler resolves all names and arities, rejects recursive call graphs and bounds expanded work, source size, nodes, depth, and IR size. It does not change the main LLVM compiler parser, typed HIR, runtime error ABI or strict verification profile.

Add/sub use LLVM unsigned overflow intrinsics; multiplication uses a zero-guarded unsigned division preflight. The first local run showed that umul.with.overflow at Wasm O0 needed __multi3 in this freestanding link; the new lowering avoids that dependency. Intermediate faults remain observable even if the consumer cancels the result. Native observers print full u64 decimal values; Wasm uses BigInt.asUintN(64). Native trap signals and Wasm RuntimeError are limited machine-level evidence, not typed Atto Error/Result/supervisor conformance.

## Bounded unsigned division candidate

This extension admits truncating u64/uint quotient with explicit zero-divisor guard. The shared emitter uses a 64-iteration restoring division loop with carry-aware unsigned subtraction; no wide divide operation is required. The helper is emitted only for division-containing units. LLVM/Wasm use a generic terminal trap (not a distinct portable guest Error ABI); Forge emits exit 71 / E_U64_DIVISION_BY_ZERO, distinct from arithmetic overflow exit 70.
